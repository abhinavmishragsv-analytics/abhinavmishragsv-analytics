## 🛠️ Featured Work

### 🚉 GCT Feasibility & Site Recommendation Engine — DFCCIL
> *AI-powered system to evaluate Goods Cargo Terminal viability across India's Dedicated Freight Corridors*

- **Schedule-I Engine:** Automated feasibility assessment using regulatory compliance logic
- **Schedule-II Engine:** Multi-factor site recommendation with an `Opportunity Index` ranking system
- Built on **Python + Streamlit**, deployed on Streamlit Cloud with secure email-based authentication
- Integrated KPI dashboards, PDF report generation, station leaderboard, and DFCCIL branding
- Corrected corridor assignments (WDFC/EDFC) and built an `Industrial_Ecosystem_Index` using weighted scoring across 11 industry types within a 30–50 km catchment radius

---

### ✈️ Airline Loyalty Analytics — Churn & Segmentation
> *End-to-end customer analytics pipeline for an airline loyalty program*

- **Churn Prediction:** XGBoost with SMOTE oversampling, tuned on AUC-ROC
- **Segmentation:** K-Means clustering with RFM & CLV scoring
- Streamlit prototype dashboard + full technical report
